# DataNord Data Champion Award 2026

As part of the Data Champion Award, I would like to present our current research based on a preliminary project. This preliminary project has established a FAIR workflow for analyzing geospatial data using R and OpenStreetMap in the field of health sciences. The workflow was presented by Nourat N. Alazza at the EHPS conference in 2025.

## Navigation

If you would like to gain insight into the workflow without touching the code, open the PDF file. If you would like to view the R code for the workflow, open the R Markdown file. The subfolders contain several files that are referenced in the R Markdown.
