# geospatial-health-research

This GitHub repository publishes a workflow on how to use geospatial data in health research from the Department of Prevention and Health Promotion at the University of Bremen. 

## Projects

### Tobacco outlets near schools [not yet published]

This project examines tobacco exposure among children and adolescents near schools using geospatial data from OpenStreetMap and Google Maps, analyzed with R.

### DataNord Data Champion Award 2026

By submitting our application for the Data Champion Award of the Data Competence Center for the Bremen Region, we aim to highlight the potential of geodata-based research in health sciences and raise awareness about the need for greater transparency in the responsibilities of authorities regarding tobacco control.
